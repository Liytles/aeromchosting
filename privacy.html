Gizlilik Politikası

Son Güncelleme: 16 Eylül 2026

1. Genel Bakış ve Taahhüt

The Aero Group tarafından geliştirilen AeroMC masaüstü yazılımı ve ilişkili web hizmetleri, kullanıcı gizliliğini temel bir ilke olarak benimser. Yazılım mimarimiz, kullanıcı verilerinin sunucularımıza gönderilmediği yerel öncelikli (local-first) prensip doğrultusunda tasarlanmıştır.

2. Toplanan ve İşlenen Veriler

AeroMC aşağıdaki veri kategorileri ile çalışır:

  • Yerel Yapılandırma ve Kimlik Bilgileri: API anahtarlarınız (Exaroton, Pterodactyl, Modrinth) ve sunucu bağlantı parolalarınız, bilgisayarınızda AeroGuard güvenlik katmanı altında AES-256-GCM algoritması ile yerel olarak şifrelenir. Ana şifreleme anahtarı diske kaydedilmez, yalnızca aktif oturum esnasında bellekte (RAM) tutulur.
  • Sunucu Günlükleri ve Teşhis Verileri: Minecraft sunucu logları, Spark performans raporları ve çökme analizi verileri tamamen yerel dosya sisteminizde işlenir. Bu veriler harici herhangi bir AeroMC sunucusuna iletilmez.
  • Webhook Bilgileri: Kullanıcı tarafından tanımlanan Discord Webhook bağlantıları, bildirim iletimi amacıyla doğrudan Discord API uç noktalarına yerel istemcinizden gönderilir.

3. Harici Ağ İstekleri

AeroMC istemcisi yalnızca aşağıdaki durumlarda harici ağ bağlantısı kurar:

  • Resmi GitHub API üzerinden yeni sürüm kontrolü yapılması.
  • Modrinth API üzerinden mod ve eklenti meta verilerinin sorgulanması.
  • Kullanıcının yapılandırdığı uzak Pterodactyl veya Exaroton API uç noktalarıyla iletişim kurulması.
  • Aternos sunucuları için SRV ve ping tabanlı çevrimiçi durum sorgularının yapılması.
  • Dil ve Bölge Uyarlaması: Arayüz dilini otomatik olarak belirlemek amacıyla kullanılan saat dilimi (timezone) ve dil tercihleri, yalnızca tarayıcınız üzerinden yerel olarak değerlendirilir. Bu veriler harici sunucularımıza kesinlikle gönderilmez, saklanmaz veya üçüncü taraflarla paylaşılmaz.

Tüm harici iletişim zorunlu olarak TLS 1.2 veya TLS 1.3 şifreleme protokolleri üzerinden yürütülür.

4. Çerezler ve Web Sitesi Analitiği

AeroMC web sitesi kullanıcıları takip eden üçüncü taraf reklam çerezleri veya izleme pikselleri barındırmaz.(Siteye ne kadar yoğunluk bindindiğine ve ne kadar ziyaret aldığına bakmak için bulunan kod hariç) İstemci taraflı işletim sistemi tespiti tamamen tarayıcınızın standart User-Agent başlığı üzerinden yerel JavaScript ile yapılır ve kaydedilmez.

5. İletişim

Gizlilik politikamız veya veri güvenliği protokollerimiz hakkında sorularınız için resmi GitHub depomuz üzerinden iletişime geçebilirsiniz.
